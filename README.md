# FootballDB

## 🇬🇧 English
**FootballDB** is a Java CLI application that simulates a database of football teams and players. Users can add and view teams and players along with their full details, edit existing records, and execute player transfers between teams while automatically tracking each player's transfer history.

### Key Highlights
- **Object-Oriented Design:** Built using clean Object-Oriented Programming (OOP) principles.
- **Fast Lookups:** Makes extensive use of `HashMap` data structures for fast retrieval and duplicate validation.
- **Data Persistence:** Automatically saves and loads application data locally using Java Serialization.

---

## 🇬🇷 Ελληνικά
Το **FootballDB** είναι μια εφαρμογή κονσόλας (CLI) γραμμένη σε Java, η οποία προσομοιώνει μια βάση δεδομένων ποδοσφαιρικών ομάδων και παικτών. Ο χρήστης μπορεί να προσθέτει και να προβάλλει ομάδες και παίκτες μαζί με όλα τα στοιχεία τους, να επεξεργάζεται υπάρχουσες πληροφορίες, καθώς και να πραγματοποιεί μεταγραφές παικτών, διατηρώντας αυτόματα το ιστορικό μεταγραφών κάθε παίκτη.

### Βασικά Χαρακτηριστικά
- **Αντικειμενοστρεφής Σχεδίαση:** Βασίζεται στις αρχές του Object-Oriented Programming (OOP).
- **Γρήγορη Αναζήτηση:** Γίνεται εκτεταμένη χρήση `HashMap` για άμεση προσπέλαση δεδομένων και έλεγχο διπλότυπων.
- **Μόνιμη Αποθήκευση:** Τα δεδομένα της εφαρμογής αποθηκεύονται και φορτώνονται αυτόματα τοπικά μέσω Java Serialization.
